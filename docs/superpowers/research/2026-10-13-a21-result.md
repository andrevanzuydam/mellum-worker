All four rung 9 failures (three A21, one control) break the same Phase 4
requirement, which only the hidden tests check: `Complaint(agent_name,
text)` must still work and get a unique `id` automatically. Mellum assigned
ids in the route only (`'Complaint' object has no attribute 'id'`), left
them `None`, or changed the constructor. Reconstructed from each run's
`diff.patch` on the phase 4 fixture; the hidden tests reproduce the
ladder's scores exactly. Every failing run passed its own test command.

## Descriptive

- No A21 run built a later phase than asked: the next phase's hidden test
  fails in all nine rung 6–8 runs, so the whole roadmap in one file did not
  pull work forward.
- The runner stopped leftover processes after 2 A21 runs and 4 control
  runs (the fix in `99493d7`); no run hit a busy port.

## What would falsify this

Rung 9 at 0/3 again with the one-file roadmap in a later phase, against a
passing control, would make the roadmap shape (or the dropped "remove or
rewrite routes that already work" bullet) a cause, not noise.
