# Terminology

- **Agent:** A system that uses a model to choose and carry out actions toward a goal.
- **Agent loop:** The repeated cycle of observing, deciding, acting, and checking results.
- **API:** An interface that lets software communicate with a model or another service.
- **Completion:** The output generated by a model.
- **Context:** All the information supplied to the model for a response.
- **Context window:** The maximum amount of information a model can handle in one interaction, measured in tokens.
- **Embedding:** A numerical representation that captures useful features and relationships in data.
- **Evaluation / eval:** A test used to measure a model’s or agent’s quality, accuracy, or behavior.
- **Fine-tuning:** Additional training that adjusts a model’s weights for particular tasks, styles, or behaviors.
- **Grounding:** Connecting a response to specific evidence or data.
- **Hallucination:** An incorrect or invented output presented as though it were reliable.
- **Harness:** The software that calls the model, supplies context, executes tools, and manages permissions.
- **Inference:** Running a trained model to generate an output.
- **Latency:** The time it takes to receive a response.
- **LLM (large language model):** A model trained on large amounts of data to process and generate language.
- **Memory:** Information saved outside the model and retrieved for later use.
- **Multimodal:** Able to process or generate more than one type of content, such as text, images, or audio.
- **N-gram:** A sequence of *n* neighboring items, usually words or tokens.
- **Parameters / weights:** The learned numbers inside a model that shape its outputs.
- **Pretraining:** The initial broad training that builds a model’s general capabilities.
- **Prompt:** The input given to a model, including questions, instructions, or examples.
- **RAG (retrieval-augmented generation):** Retrieving relevant information and adding it to the model’s context before it answers.
- **System instructions:** Instructions that define the model’s role, boundaries, and behavior.
- **Temperature:** A setting that influences randomness when selecting output tokens.
- **Token:** A piece of text, such as a word, part of a word, or punctuation.
- **Token ID:** The number assigned to a token in a tokenizer’s vocabulary.
- **Tokenizer:** The system that converts text into token IDs and back again.
- **Tool calling:** A model producing a structured request for software to perform an action.
- **Training:** The process of adjusting a model’s weights using data.
- **Vector:** A list of numbers used to represent information mathematically.
