# What this is

This Learning Center teaches you how to run a small coding model locally behind Pi — and fix what goes wrong, with evidence. It is built for developers on macOS, Linux, or Windows who know a terminal and Python or Node.

It grew out of [mellum-worker](https://github.com/pauleveritt/mellum-worker), a project that measured the "Mellum as a bounded coding worker" recipe using a ladder of evals recorded in `docs/ladder/`. Every finding here comes from those runs or from [Andre van Zuydam](https://github.com/andrevanzuydam)'s pull requests.

This is [a collaboration between Andre and Paul](../credits.md). It is not the worker's manual — for that, see the [README on GitHub](https://github.com/pauleveritt/mellum-worker/blob/main/README.md).
