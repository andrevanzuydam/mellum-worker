# Getting started

This track is in a fixed order. Lesson 2 builds on the result of lesson 1.

## Lessons

1. **[Base Pi on llama.cpp](base-pi-on-llamacpp.md)** — Install `uv`, llama.cpp and the Mellum weights, chat with the model, and connect Pi through a private profile to get an answer. Start here.
2. **[Make a mini harness](harness.md)** — Write a small harness that runs Pi on a task in a fresh directory and scores it, then read the run's telemetry.
3. **A suite and the telemetry** (phase LC.3A) — Add a medium and a hard task, watch base Pi pass easy and struggle on hard, and read why.
