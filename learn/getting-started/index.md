# Getting started

This track is in a fixed order. Lesson 2 builds on the result of lesson 1.

## Lessons

1. **Base Pi on Ollama** (coming, phase L.2) — Install Ollama and the Mellum GGUF, chat with the model, then connect Pi through a provider template and get an answer.
2. **A mini harness and a suite** (coming, phase L.3) — Build a small eval harness that runs Pi on a task and scores it; write an easy, a medium, and a hard task; watch base Pi pass easy and struggle on hard; read the telemetry to see why.
