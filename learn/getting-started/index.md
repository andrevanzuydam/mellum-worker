# Getting started

This track is in a fixed order: each lesson builds on the one before, and
each ends with a check you can run.

## Lessons

1. **[Base Pi on llama.cpp](base-pi-on-llamacpp.md)** — Install `uv`, llama.cpp and the Mellum weights, chat with the model, and connect Pi through a private profile to get an answer. You finish with a server, a `chat` command, and base Pi answering. Start here.
2. **[Make a mini harness](harness.md)** — Write a small harness that runs Pi on a task in a fresh directory and scores it. You finish with one isolated run and a score line.
3. **[A suite and the telemetry](suite.md)** — Add a medium and a hard task, grade the model's files, and read why a run failed from its trace. You finish with three scored tasks and three graders.
