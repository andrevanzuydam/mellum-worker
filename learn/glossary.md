# Glossary

- **Learning Center**: the whole Zensical site under `learn/`.
- **Track**: a group of lessons with a recommended order. There are three: Getting started, Paul's findings, Andre's findings.
- **Lesson**: one page that teaches one thing. Getting started lessons build on each other; a findings lesson stands alone and lists its prerequisites.
- **Six-step template**: Problem → Eval case → Evidence of the problem → Solution → Validation → Interpretation. Every findings lesson uses it.
- **Interpretation**: the closing narrative of a lesson: what the evidence means, how far its badges let you trust it, and what is still open.
- **Badge**: a label on each of steps 1–5 saying what the step rests on: `reference-run`, `cited`, `screen`, or `conjecture`.
- **Reference run**: a preregistered ladder run on llama.cpp, recorded in `docs/ladder/`, made for a lesson.
- **Mini harness**: the small eval harness learners build in Getting started lesson 2, kept in `learn/code/`. It is not the ladder.
