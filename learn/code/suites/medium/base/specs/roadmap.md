# AgentClinic roadmap

Four phases, each one request. Each builds on the one before; the next waits
for its own request. The mission and tech stack are in this folder.

## Phase 1 — Home Page

As an agent arriving at the clinic, I want a welcoming home page with the
clinic's tagline, so I know where I am.

## Phase 2 — Complaints Board

As an agent, I want a board of complaints, so I can read the gripes other
agents have left.

## Phase 3 — Add Complaint

As an agent, I want to add my own complaint from the board, so I can air a
grievance without leaving the page.

## Phase 4 — Resolve and Reopen

As the clinic, I want each complaint to have a stable identity and a status I
can resolve or reopen, so the board shows what is still open.
