# Small AI Learning Center

Python developers are interested in how agentic coding can help on routine work on their laptop. This space has
progressed rapidly but the truth remains: small models need agents that help them stay on track.

This center teaches you how to run a small coding model locally behind Pi — and fix what goes wrong, with evidence.
Every finding is told the same way: the problem, how to reproduce it, the evidence, the fix, and whether the fix worked.
You can see exactly how strong each piece of evidence is.

Start with the **Getting started** track: five lessons that go from llama.cpp to a graded eval harness. After that, any
findings lesson stands alone and lists what you need first.

Each step of a lesson carries an [evidence badge](about/evidence.md) — from measured runs to reasoned conjecture — so
you always know what is proven and what is still open.

## Tracks

- [Introduction](introduction/index.md) — Demystifying agents and harnesses, the first principal, study
  the [terminology](glossary.md).
- [Getting started](getting-started/index.md) — Set up a local model and build an eval harness. Fixed order.
- [Lessons](lessons/index.md) — findings from the mellum-worker phases, its ablations, and Andre van Zuydam's pull
  requests. Each stands alone.
